## Digimon Survivor

A fan-made, mobile-first survival arena built with dependency-free HTML, CSS, and Canvas 2D. Choose a partner, outrun the swarm, absorb data, and digivolve before the five-minute protocol ends.

### Play

Open the hosted project, or run any static server from this directory:

```bash
python3 -m http.server 3000
```

Then visit `http://localhost:3000`.

### Controls

- **Touch:** drag anywhere to move, tap `DASH` to burst forward.
- **Keyboard:** `WASD` / arrow keys to move, `Space` or `Shift` to dash, `Esc` / `P` to pause.
- **Tilt:** enable `TILT` in the menu, hold the device level to calibrate, then tilt to steer. iOS asks for motion permission the first time.
- **Sound:** synthesized music and effects start after the first interaction. Toggle with the sound button or `M`.

### Gameplay

- Pick **Agumon**, **Gabumon**, or **Patamon**.
- Attacks fire automatically; collect data shards to level up.
- Choose one of three upgrades on every level-up.
- Digivolve at levels **5** and **12**.
- Bosses arrive at **2:00** and **4:00**. Survive the full **5:00** to win.
- Your best run is saved locally in the browser.

### Notes

- No build step and no external assets, fonts, or game libraries.
- `TILT` is optional and requires a device with motion sensors.
- This is an unofficial fan project. Digimon and related names are trademarks of their respective owners; all visuals here are original procedural artwork.
